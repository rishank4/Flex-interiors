# Flex Interiors — Architectural Interiors Website

A premium, minimal, 6-page website for **Flex Interiors**, an architectural interior design studio based in Calicut, Kerala.

## Pages
- **Home** — Hero slider, studio intro, services preview, testimonials
- **About** — Studio story, team, design philosophy
- **Services** — 9 architectural practice areas with enquiry links
- **Portfolio** — 16 projects with category filter, lightbox gallery
- **Process** — 8-stage methodology timeline, FAQ accordion
- **Contact** — Multi-channel form (email + WhatsApp), business hours, Google Map

## Tech Stack
- Plain HTML5 + CSS3 + Vanilla JavaScript — zero dependencies
- Cormorant Garamond (headings) + Inter (body) via Google Fonts
- Responsive at 375px, 768px, 1440px

## Quick Start
```bash
cd "Flex interiors"
python -m http.server 3000
# Open http://localhost:3000
```

## Contact Config
All studio contact details (phone, email, WhatsApp, address, hours) are centralised in `assets/js/config.js`.

## Hosting
Deploy to **Netlify**, **Vercel**, or **Cloudflare Pages** by dragging the folder or connecting this repository.
